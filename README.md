# 实用工具集合

这里包含两个简单实用的小工具。

## 🍅 番茄时钟

简单易用的桌面番茄钟应用，帮助你保持专注，提高工作效率。

### 功能

- ⏱️ **25分钟工作时间** - 专注工作，提升效率
- ☕ **5分钟休息时间** - 工作完成后自动切换
- ▶️ 开始/暂停/重置控制
- 📊 进度条显示
- 🔔 计时结束提示音

### 运行

```bash
python pomodoro_timer.py
```

### 依赖

- Python 3.x
- tkinter (通常随Python安装)

---

## 👶 新生儿护理记录

记录宝宝的吃奶、睡眠、排便情况，手机和电脑都能用。

### 功能

- 🍼 **吃奶记录** - 母乳/配方奶/混合，记录喂养量
- 😴 **睡眠记录** - 记录入睡/醒来时间
- 💩 **排便记录** - 便便/尿尿/混合
- 📱 响应式设计 - 手机电脑完美适配
- 💾 本地存储 - 数据保存在浏览器中

### 使用

直接用浏览器打开 `baby-tracker.html` 即可使用，无需安装任何依赖。

手机使用：可以把文件传到手机打开，或部署到 GitHub Pages。

### 在线使用

访问：https://elwinfan.github.io/pomodoro-clock/baby-tracker.html
